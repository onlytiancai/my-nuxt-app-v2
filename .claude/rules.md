# Project Rules

## Tech Stack

- **Framework**: Nuxt 4 (v4.3.1+)
- **Vue**: Vue 3.5.28+
- **CSS Framework**: Tailwind CSS (via @nuxtjs/tailwindcss)
- **Package Manager**: pnpm
- **Router**: Vue Router (Nuxt pages)

## Directory Structure

```
my-nuxt-app/
├── app/                      # Source directory (srcDir)
├── server/                   # Server-side code (serverDir)
```
